# KSPS Special Care (`kspsSpecialCare`)

ระบบบริหารจัดการแพ็กเกจบริการพิเศษ แยกตามหน่วยบริการเพื่อจัดหารายได้เสริมโรงพยาบาลโคกศรีสุพรรณ (Khok Si Suphan Hospital) พร้อมระบบจองคิวนัดหมายออนไลน์ ตรวจสอบสิทธิ์การรักษาจากฐานข้อมูล **HOSxP (Read-Only)** และยืนยันตัวตนผ่านระบบ **ThaID (กรมการปกครอง DOPA OpenID Connect v2)**

---

## ฟีเจอร์หลัก

1. **ระบบแพ็กเกจบริการพิเศษแยกตามหน่วยบริการ (Service Units):**
   - คลินิกพิเศษผู้ป่วยนอก (OPD VIP & คลินิกนอกเวลา / Fast Track / ตรวจสุขภาพประจำปี)
   - ศูนย์การแพทย์แผนไทยและการแพทย์ทางเลือกพิเศษ (นวดรักษา ประคบสมุนไพร สปา)
   - คลินิกทันตกรรมพิเศษนอกเวลา (Dental Special Care)
   - คลินิกกายภาพบำบัดพิเศษ (Physical Therapy Plus - High Power Laser / Ultrasound)
   - ศูนย์ตรวจวิเคราะห์สุขภาพครบวงจร (Executive Checkup & Lab)
   - หอผู้ป่วยพิเศษ & การดูแลมารดา-ทารก (VIP Ward ตึกร่มโพธิ์ 84 ปี)
2. **การคำนวณสิทธิ์เบิกจ่ายและส่วนเกินอัตโนมัติ:**
   - รองรับ **สิทธิข้าราชการ/กรมบัญชีกลาง (`OFC`)**, **สิทธิ อปท. (`LGO`)**, **สิทธิบัตรทอง (`UCS`)**, **สิทธิประกันสังคม (`SSS`)**, และ **ชำระเงินเอง (`CASH`)**
   - ดึงข้อมูล `HN` และสิทธิ์การรักษาล่าสุดจากตาราง `patient`, `ovst`, `pttype` ของฐานข้อมูล **HOSxP** แบบ Read-Only
3. **ระบบจัดการตารางวัน-เวลาเปิดให้บริการสำหรับหน่วยบริการ:**
   - แต่ละหน่วยบริการสามารถเพิ่มแพ็กเกจใหม่ กำหนดวันประจำสัปดาห์ (จ.-อา.) หรือกำหนดวันที่เปิดเฉพาะกิจ พร้อมกำหนดช่วงเวลาและโควตาจำนวนคิวสูงสุดต่อรอบ
4. **เชื่อมต่อระบบพิสูจน์และยืนยันตัวตน ThaID (DOPA OAuth 2.0):**
   - รองรับ Callback Endpoint ที่พอร์ต `3601` (`http://147.50.107.211:3601/`)

---
